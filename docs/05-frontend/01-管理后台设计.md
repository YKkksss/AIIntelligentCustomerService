# 管理后台设计

## 1. 工程
- `frontend/`：Vue 3 + Vite + TypeScript + Element Plus + Pinia + Vue Router + axios。
- API 类型由后端 `openapi.json` 生成：`npx openapi-typescript http://localhost:8000/openapi.json -o src/api/schema.d.ts`，避免前后端字段不一致。
- 开发：`npm run dev`（:5173），Vite 代理 `/api` → `http://localhost:8000`。
- 鉴权：token 存内存 + `sessionStorage`（关闭浏览器即失效）；axios 拦截器遇 `TOKEN_EXPIRED` 自动刷新一次，失败跳登录。
- 权限：路由 `meta.roles` + 指令 `v-perm="'kb:write'"` 隐藏按钮；后端仍做最终校验。
- SSE：`@microsoft/fetch-event-source`。

## 2. 布局
左侧菜单（全局：仪表盘、应用、用户、审计；进入应用后：概览、配置、知识库、调试对话、评测、API Key、会话日志、反馈、成员），顶部为应用切换器和用户菜单。

## 3. 页面
| 路由 | 页面 | 要点 |
|---|---|---|
| `/login` | 登录 | 锁定提示；首次登录强制改密 |
| `/dashboard` | 全局仪表盘 | 各应用对话量、拒答率、转人工率、点踩率、延迟趋势（ECharts） |
| `/apps` | 应用列表 | 卡片：名称、状态、文档数、近 7 天对话；新建（S） |
| `/apps/:id/overview` | 概览 | 该应用指标 + 最近失败文档 + 最近点踩 |
| `/apps/:id/settings` | 配置 | 分组表单：基础（名称、开场白、提示词、风格、兜底）、检索参数（滑块 + 说明 tooltip）、转人工规则、切块参数（修改时弹窗提示"需要重建索引，是否立即重建"）、自定义词典；显示 config_version；保存写审计 |
| `/apps/:id/knowledge` | 知识库 | 拖拽多文件上传 + URL 导入；表格：标题、类型、大小、状态标签、进度条、切块数、更新时间；处理中每 3s 轮询；失败行显示错误与"重试"；批量删除/重建；重复文件提示 |
| `/apps/:id/knowledge/:docId` | 文档详情 | 元信息；切块列表（序号、标题路径、token、正文折叠、启用开关、搜索） |
| `/apps/:id/debug` | **调试对话** | 左：聊天区（流式、引用角标点击定位）；右：检索面板 Tab ——「改写问题」「向量命中」「关键词命中」「融合」「重排序（分数条形图，阈值线）」「决策与原因」「耗时瀑布」「token」；顶部"临时参数"抽屉可覆盖 rag_config 对比；"新会话"按钮；每条回答可"加入评测集" |
| `/apps/:id/eval` | 评测集 | 评测集列表、用例表格（增删改、CSV 导入导出）、"运行评测" |
| `/apps/:id/eval/runs/:runId` | 评测结果 | 指标卡（Recall@5、引用命中、正确率、忠实度、拒答准确率、误拒率、P95 延迟）；逐题表格可筛选失败项；与上次运行对比（差值上下箭头） |
| `/apps/:id/keys` | API Key | 列表（前缀、scope、限额、过期、最近使用、状态）；创建后弹窗显示明文 + 复制 + "我已保存"确认；吊销二次确认；**接入示例**：curl / Python / OpenAI SDK / JS 代码块，自动填入 BASE 与 APP ID，Key 用占位符 |
| `/apps/:id/conversations` | 会话日志 | 筛选（渠道、时间、转人工、点踩、关键字）；详情抽屉显示全部消息、引用、trace |
| `/apps/:id/feedback` | 反馈 | 点踩列表，标记已处理，一键转评测用例 |
| `/apps/:id/members` | 成员 | 添加用户并指定 app_admin / viewer |
| `/users` | 用户（S） | 新建、禁用、重置密码 |
| `/audit` | 审计日志 | 筛选 + diff 查看 |
| `/system` | 系统信息（S） | 版本、模型配置、依赖状态 |

## 4. 交互约定
- 危险操作（删除、吊销、重建全部）二次确认，输入应用名确认删除应用。
- 所有表格支持分页、空状态、加载骨架；错误统一 `ElMessage` 显示 `message` + `request_id`。
- 中文界面；时间按浏览器时区显示（`dayjs`）。
