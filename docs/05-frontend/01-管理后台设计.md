# 管理后台设计

> 现状（2026-10-19，M4.1 ④）：骨架已落地——登录 / 概览 / 用户 / 审计 / 改密五个页面、布局与菜单、应用切换、`v-perm` 与 `authGuard`、axios 刷新队列、类型生成脚本、Vitest 基座（33 例、覆盖率 84.88% 语句）。其余页面按 M4.2–M4.6 与 M5 逐步补齐（工程取舍见 [ADR-0018](../02-architecture/adr/0018-管理后台工程取舍.md)），分步见[后续里程碑详细计划 M4](../00-planning/06-后续里程碑详细计划.md)。设计稿：`ui/aics-admin.pen`。前端单元测试用 Vitest（逻辑层覆盖率 ≥ 80%），里程碑冒烟用 Playwright（设计讨论 0009 D13）。

## 1. 工程
- `frontend/`：Vue 3 + Vite + TypeScript + Element Plus + Pinia + Vue Router + axios。
- 工程取舍（2026-10-19，[ADR-0018](../02-architecture/adr/0018-管理后台工程取舍.md)）：自建骨架、**不整仓 fork** 现成模板（依赖版本已比模板新，fork 等于降级）；后端管理接口手写 `modules/<m>/admin_router.py`（前缀 `/api/v1/admin`，JWT），不引入 BaaS/CRUD 框架。
- API 类型由后端 `openapi.json` 生成：`npm run gen:api`（`scripts/gen-api.mjs` 先让后端 dump `openapi.json`，再调用 `openapi-typescript` 写 `src/api/schema.d.ts`；生成的中间文件 `openapi.json` 已 gitignore，`schema.d.ts` 入库）。后端多数路由用 `JSONResponse`、没有 `response_model`，所以响应体类型仍以 `src/api/admin.ts` 的手写声明为准——两者不一致时以契约为准并补 `response_model`。
- 开发：`npm run dev`（:5173），Vite 代理 `/api` → `http://localhost:8000`。
- 鉴权：token 存内存 + `sessionStorage`（关闭浏览器即失效）；axios 拦截器遇 `TOKEN_EXPIRED` 用单飞 Promise 刷新一次，失败跳登录。
- 权限：`/auth/me` 返回当前用户在各应用的 RBAC 权限列表；路由 `meta.permission` + 指令 `v-perm="'kb.write'"` 隐藏按钮（使用后台 RBAC 点分权限名，**不是** API Key scope `kb:write`，两套命名见[安全设计 §2.1](../08-security/01-安全设计.md)）；后端仍做最终校验。
- SSE：`@microsoft/fetch-event-source`。

## 2. 布局
左侧菜单（全局：仪表盘、应用、用户、审计；进入应用后：概览、配置、知识库、调试对话、评测、API Key、会话日志、反馈、成员），顶部为应用切换器和用户菜单。

## 4. 交互约定
- 危险操作（删除、吊销、重建全部）二次确认，输入应用名确认删除应用。
- 所有表格支持分页、空状态、加载骨架；错误统一 `ElMessage` 显示 `message` + `request_id`。
- 中文界面；时间按浏览器时区显示（`dayjs`）。

## 5. 实现状态（M4.1 ④，2026-10-19）
| 路由 | 状态 | 说明 |
|---|---|---|
| `/login` | ✅ | 真登录、`ACCOUNT_LOCKED` 文案、登录后回跳 `redirect` |
| `/`（概览） | ✅ 骨架 | 当前用户、应用数、权限数；完整指标在 M4.2 |
| `/users` | ✅ | 列表 / 搜索 / 新建 / 禁用 / 重置密码（一次性弹窗）/ 删除，权限 `user.admin` |
| `/audit` | ✅ | 动作筛选、游标「加载更多」、`diff` 详情抽屉，权限 `audit.read` |
| `/password` | ✅ | 改密后换新令牌、旧 access 立即失效 |
| 其余页面 | 计划 | 按 M4.2–M4.6 与 M5 逐页补，页面清单见 §3 |

- 路由守卫 `authGuard`（`src/router/index.ts`）：未登录跳 `/login?redirect=`；已登录但身份未加载先 `GET /auth/me`；`meta.permission` 不足回概览。
- 应用切换器：切换后若当前页权限不足自动回概览（`switchApp` 不触碰 token）。
- 菜单按 `meta.menu` + `auth.can(meta.permission)` 过滤，权限矩阵与后端 `modules/auth/permissions.py` 一致。
