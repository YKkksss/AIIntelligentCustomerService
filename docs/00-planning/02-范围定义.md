# 范围定义

## v1（本期必须交付）
**开放接口**
- 应用级 API Key：哈希存储、限流、过期时间、吊销、最近使用时间。
- 对话接口 `POST /api/v1/apps/{app_id}/chat`：阻塞与 SSE 流式；返回 `conversation_id`、引用、是否转人工、意图；会话按应用配置空闲关闭（默认 10 分钟，关闭前 1 分钟提醒）。
- OpenAI 兼容接口 `POST /v1/chat/completions`（`model` = 应用 ID），支持 `stream`；可用 `X-AICS-Conversation-Id` 关联服务端会话。
- 转人工：状态机、`handoff_ai_mode`（continue / wait）、排队超时、可选服务时间（非服务时间转留言）、接入后无消息超时、待回访列表、固定格式出站 Webhook（签名、重试）、人工坐席入站接口、会话事件流 SSE。
- 知识库接口：上传、列表、详情（处理进度）、替换、改标题、删除、重建、URL 导入。
- 反馈接口：对某条回答点赞 / 点踩。

**RAG 能力**
- 规则层 + 意图识别 → 按 token 预算组装多轮历史（滚动摘要、关键事实）→ 问题改写 → 混合检索（向量 + 关键词）→ RRF 融合 → 重排序 → 可答性判断 → 生成 / 拒答 / 转人工。
- 支持 PDF、DOCX、MD、TXT、HTML / 网页 URL；结构化切块并保留标题路径。

**管理后台**
- 登录、用户与角色（super_admin / app_admin / viewer）。
- 应用管理、知识库管理（上传、进度、切块预览、重建、删除）。
- 调试对话（显示改写问题、检索块、各阶段分数、耗时、token）。
- 评测集与评测运行（含反馈转用例、提示词版本记录）、API Key 管理与接入示例、对话日志与反馈、待复核切块、审计日志、仪表盘（每日统计）。

**工程**
- 后台任务（Celery + RabbitMQ）、结构化日志、健康检查、Prometheus 指标端点。
- 单元 / 集成测试、评测脚本、ruff、pre-commit、CI 检查。
- 部署文档、备份脚本、运维手册。

## v2（下一期）
- 可嵌入网页的聊天组件（一行 `<script>`）。
- OCR（扫描件 PDF、图片）：RapidOCR / MinerU。
- 对象存储（MinIO / S3）。
- 人工坐席工作台 UI（v1 只提供坐席接口与 Webhook，由接入方的坐席平台对接）。
- 工具调用：应用可配置外部 HTTP 工具（查订单等），带审批。
- 多租户（租户 → 应用两级）、计费与用量报表导出。
- 问答对（FAQ）直接匹配、同义词表、自动生成评测问题。
- 更多 Webhook 事件（文档处理完成等；转人工与会话事件 v1 已提供）。

## 不做（Out of scope）
- 模型训练 / 微调。
- 语音、视频客服。
- 公网 SaaS 化运营（v1 定位内网 / 合作方使用）。
- 100% 准确率承诺：系统设计目标是"答对大多数、答不了不乱说"。
