# 术语表

| 术语 | 解释 |
|---|---|
| 应用（App） | 一个客服机器人。拥有自己的知识库、配置、API Key、会话。所有数据按 `app_id` 隔离 |
| 文档（Document） | 上传到某个应用知识库的一份资料（文件或网页） |
| 切块（Chunk） | 文档切成的小段文字，是检索的最小单位 |
| 标题路径（heading_path） | 切块所在的章节层级，如 `售后政策 > 退货 > 时效` |
| 向量化（Embedding） | 把文字变成一串数字（向量），意思相近的文字向量也相近 |
| 向量检索 | 用问题的向量找最相近的切块向量（Qdrant） |
| 关键词检索 | 按词语匹配查找（PostgreSQL 全文检索 + jieba 分词） |
| 混合检索 | 两种检索结果合并，互补长处 |
| RRF | Reciprocal Rank Fusion，按排名融合多路检索结果：`score = Σ 1/(k + rank)`，k=60 |
| 重排序（Rerank） | 用专门的模型对候选切块逐个和问题打相关性分，重新排序 |
| 问题改写（Condense） | 把"那它呢？"这类依赖上下文的追问改写成完整独立的问题 |
| 可答性判断 | 判断检索到的内容是否足以回答，决定生成、拒答还是转人工 |
| 转人工（Handoff） | 告诉调用方"这个问题需要人工处理"，由接入方系统接管 |
| SSE | Server-Sent Events，服务器逐段推送文本，实现"打字机"效果 |
| LangGraph | 用"节点 + 边 + 状态"编排 LLM 流程的框架 |
| Celery | Python 后台任务框架；RabbitMQ 作为消息代理（broker） |
| vhost | RabbitMQ 的虚拟主机，相当于独立的命名空间 |
| tsvector | PostgreSQL 全文检索用的分词结果类型 |
| 评测集 | 一组"问题 + 期望答案 / 期望命中文档"，用于量化准确率 |
| ADR | Architecture Decision Record，架构决策记录 |
