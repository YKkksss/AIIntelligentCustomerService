# 风险与对策

| # | 风险 | 可能性 | 影响 | 对策 |
|---|---|---|---|---|
| R1 | 服务器内存紧张（约 5.7 GB 可用） | 中 | 高 | Qdrant 限 1 GB；向量 on-disk payload；Worker 在开发机运行；上线前复查 `free -h` |
| R2 | 共享 PG/Redis/RabbitMQ 被其他项目重启或升级 | 中 | 中 | 独立库/库号/vhost；连接池自动重连；健康检查告警；关键操作幂等 |
| R3 | 云模型（DeepSeek / 百炼）限流、超时、下线模型 | 中 | 高 | 供应商抽象 + 超时重试 + 熔断；模型名放配置；关注官方下线公告（gte-rerank 已于 2026-05 下线，改用 qwen3-rerank） |
| R4 | 回答幻觉 | 中 | 高 | 阈值拒答 + 可答性判断 + 只按上下文提示词 + 引用校验 + 评测回归 |
| R5 | 提示词注入（用户或文档内容） | 中 | 高 | 见安全设计：上下文隔离标记、系统提示优先、输出检查 |
| R6 | 复杂 PDF（表格、多栏）解析质量差 | 高 | 中 | 切块预览让管理员发现问题；v2 引入 MinerU |
| R7 | 中文关键词检索效果 | 中 | 中 | jieba 预分词 + 自定义词典（每个应用可配置） |
| R8 | 密钥泄露（百炼 Key 曾在聊天中出现） | 已发生 | 高 | 立即轮换；所有密钥只在 `.env`；gitleaks 扫描 |
| R9 | 换向量模型后旧向量不兼容 | 低 | 中 | 集合名带模型与维度；重建任务；切换前双写不需要，重建完成再切 |
| R10 | 初学者开发，周期拉长 | 中 | 中 | 分阶段交付，每阶段可运行；先做核心链路再做后台细节 |
