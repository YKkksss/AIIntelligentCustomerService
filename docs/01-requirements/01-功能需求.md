# 功能需求

优先级：P0 = v1 必须，P1 = v1 尽量，P2 = v2。

## 1. 应用管理（APP）
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-APP-01 | 创建/编辑/停用/删除应用。字段：名称、描述、头像、开场白、系统提示词、回答风格（简洁/详细/自定义）、兜底话术、语言 | P0 |
| FR-APP-02 | 检索参数：`vector_top_k`(默认20)、`keyword_top_k`(20)、`rerank_top_n`(5)、`rerank_threshold`(0.35)、`enable_rerank`、`judge_with_llm`、`judge_gray_upper`(0.5)；上下文参数 `history_token_budget`(3000)、`compact_trigger_tokens`(6000)、`keep_recent_turns`(4)、`enable_facts`、`enable_history_recall`、`summary_model`、`openai_temp_summary`；模型 `llm_model`（从模型注册表选择，保存时校验 80% 窗口） | P0 |
| FR-APP-03 | 转人工规则：关键词命中（如"人工""投诉"）、连续 N 次拒答、可答性判断为否时是否转人工、转人工话术 | P0 |
| FR-APP-04 | 切块参数：`chunk_size`(500 token)、`chunk_overlap`(80)、自定义分隔符、按标题切分开关、切分策略；一键预设（通用/法律法规/学术论文/FAQ/产品手册/合同协议，配置文件定义，填充后可修改）；可选父子切块（子块检索、父块送入模型）；修改后提示需重建索引 | P0 |
| FR-APP-05 | 应用级自定义词典（jieba，每个应用独立分词器实例），修改后自动重新分词切块与消息 | P1 |
| FR-APP-06 | 复制应用（含配置，不含文档） | P1 |
| FR-APP-07 | 删除应用：立即进入 `deleting`（Key 吊销、接口不可见），异步清理全部数据，进行中的任务中止 | P0 |

## 2. 知识库（KB）
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-KB-01 | 上传 PDF/DOCX/MD/TXT/HTML，单文件 ≤ 50MB，支持批量 | P0 |
| FR-KB-02 | 通过 URL 导入网页 | P0 |
| FR-KB-03 | 同应用内按 SHA-256 去重，重复上传返回已有文档 | P0 |
| FR-KB-04 | 状态 `queued → parsing → indexing → done / failed`（删除中 `deleting`），显示进度百分比与失败原因；重建/替换期间旧版本继续可检索 | P0 |
| FR-KB-05 | 切块预览：序号、标题路径、正文、token 数；可搜索 | P0 |
| FR-KB-06 | 单文档重建、整个应用重建（配置变更后）；版本化构建，完成后原子切换 | P0 |
| FR-KB-07 | 删除文档：立即不可检索，向量异步清理 | P0 |
| FR-KB-08 | 替换文档：同一文档 ID 上传新文件，构建新版本后原子切换、清理旧切块；新文件与本文档相同则不处理，与其他文档重复则拒绝（设计见文档处理流水线 §5） | P1 |
| FR-KB-09 | 禁用单个切块（不删除，不参与检索） | P1 |
| FR-KB-10 | 注入检测命中的切块标记为待复核，复核前不参与检索；后台"待复核切块"列表可通过或禁用 | P0 |
| FR-KB-11 | 修改文档标题立即生效，无需重建（标题不参与向量化） | P1 |

## 3. 问答（CHAT）
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-CHAT-01 | 多轮对话，按 `conversation_id` 续聊；无 ID 时新建；会话空闲超过应用 `idle_close_minutes`（默认 10 分钟，平台默认可在系统设置修改）自动关闭，关闭前 `idle_notice_before_minutes`（默认 1）分钟发送提醒 `idle_close_notice`；向已关闭会话发消息自动新建会话并返回新 ID | P0 |
| FR-CHAT-02 | 阻塞与 SSE 流式两种模式 | P0 |
| FR-CHAT-03 | 回答带引用：`chunk_id`、`document_id`、`document_title`、`heading_path`、`snippet`、`score`、`page` | P0 |
| FR-CHAT-04 | 检索不足时返回兜底话术，`answer_type=refused` | P0 |
| FR-CHAT-05 | 满足转人工规则时 `handoff=true` 并返回原因；会话进入转人工状态机（none → pending → accepted → released），立即通过出站 Webhook 推送 `handoff.requested` | P0 |
| FR-CHAT-22 | `handoff_ai_mode`：`continue`（坐席接入前 AI 继续回答）/ `wait`（AI 停止，回复等待话术）；坐席接入后 AI 停止，结束后恢复 | P0 |
| FR-CHAT-23 | 人工坐席入站接口（scope `handoff:write`）：接入、发送人工回复（`role=human_agent`）、结束、待处理列表 | P0 |
| FR-CHAT-25 | 排队超时：pending 超过 `handoff_queue_timeout_minutes`（默认 5）未接入 → 自动退出排队、发送 `queue_timeout_text`、回到 AI、标记待回访、推送 `handoff.queue_timeout` | P0 |
| FR-CHAT-26 | 服务时间（可选，周计划 + 时区，未配置 = 7×24）：非服务时间触发转人工不排队，发送 `offline_text`、标记待回访、推送 `handoff.offline` | P0 |
| FR-CHAT-27 | 接入后双方 `handoff_accepted_idle_minutes`（默认 30）无消息 → 自动结束人工并关闭会话，推送事件；后台保留强制释放 | P0 |
| FR-CHAT-28 | 待回访列表与标记已回访（后台），统计排队超时次数与非服务时间转留言次数 | P0 |
| FR-CHAT-24 | 固定格式出站 Webhook（HMAC 签名、重试、投递记录与重发）与会话事件流 SSE（空闲提醒、人工回复、状态变化） | P0 |
| FR-CHAT-06 | 接入方可传 `user_id`（外部用户标识）与 `metadata` | P0 |
| FR-CHAT-07 | OpenAI 兼容接口；默认无状态（历史取自请求 messages），带 `X-AICS-Conversation-Id` 时使用服务端会话 | P0 |
| FR-CHAT-08 | 调试模式（仅后台，viewer 可用）：返回改写问题、各路检索结果、分数、耗时、提示词版本；调试会话不计入统计 | P0 |
| FR-CHAT-09 | 反馈：点赞/点踩 + 备注 | P0 |
| FR-CHAT-10 | 历史按 token 预算组装（近期原文 + 滚动摘要），至少保留 `keep_recent_turns` 轮原文；原文全量保存 | P0 |
| FR-CHAT-11 | 未被摘要覆盖的原文超过阈值时异步压缩为结构化摘要，不阻塞回答，失败不影响对话 | P0 |
| FR-CHAT-12 | 关键事实槽：压缩时抽取 + 每轮从意图槽位（`order_no`、`product`、`phone`）即时写入，按会话 upsert 保存 | P1 |
| FR-CHAT-13 | 按需回查：问题指代早期内容时检索本会话历史消息补充上下文 | P1 |
| FR-CHAT-14 | OpenAI 兼容无状态请求按同一预算裁剪调用方历史，超出时请求内临时摘要（`openai_temp_summary` 可关闭），摘要不落库 | P0 |
| FR-CHAT-15 | 调试对话展示本轮上下文构成与 token 分布；会话日志可查看摘要版本 | P1 |
| FR-CHAT-16 | 意图识别规则层：敏感词安全拒答、转人工关键词、寒暄短句完全匹配后模板回复（不调 LLM） | P0 |
| FR-CHAT-17 | 改写与意图合并为一次 LLM 调用，识别 `kb_qa`、`chitchat`、`human`、`out_of_scope`、`action`、`clarify`；超时、解析失败、低置信一律按 `kb_qa` 处理 | P0 |
| FR-CHAT-18 | 寒暄、超范围、追问不检索、不带引用、不计入连续拒答；`human` 转人工；`action` v1 转人工（v1.1 接工具） | P0 |
| FR-CHAT-19 | 意图配置按应用可调（`rag_config.intent`：开关、启用意图、词表、话术、阈值） | P0 |
| FR-CHAT-20 | 响应与调试 trace 返回意图、置信度、判定来源；会话日志可按意图筛选 | P0（日志筛选 P1） |
| FR-CHAT-21 | 向量快速通道：意图示例句相似度 ≥ 阈值时跳过 LLM 分类（M5 视评测数据决定） | P2 |

## 4. 开放接口与 Key（KEY）
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-KEY-01 | 每个应用可建多个 Key；明文只在创建时显示一次 | P0 |
| FR-KEY-02 | Key 属性：名称、权限范围（`chat`、`kb:read`、`kb:write`、`handoff:write`）、RPM、日配额、过期时间、IP 白名单(P1) | P0 |
| FR-KEY-03 | 吊销立即生效；记录最近使用时间 | P0 |

## 5. 评测（EVAL）
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-EVAL-01 | 评测集 CRUD；用例：问题、期望答案、期望文档（文档 ID）、是否应拒答、标签 | P0 |
| FR-EVAL-02 | CSV 导入导出；期望文档可写 ID 或唯一标题，标题不存在或重名时报错并列出行号 | P0 |
| FR-EVAL-03 | 运行评测（后台任务，复用线上对话流程 `RunMode.eval`），记录配置快照、提示词版本、模型与指标 | P0 |
| FR-EVAL-04 | 两次运行对比，逐题看差异 | P1 |
| FR-EVAL-05 | 从点踩反馈生成用例（带入问题与会话历史），反馈记录关联用例并标记已处理 | P1 |
| FR-EVAL-06 | 用例可标注期望意图；输出意图准确率、寒暄误拒率、误转人工率、知识问答漏答率 | P0 |

## 6. 用户、日志、审计（ADM）
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-ADM-01 | 登录（邮箱+密码）、修改密码、登录失败 5 次锁 15 分钟 | P0 |
| FR-ADM-02 | 角色：super_admin 全局；app_admin / viewer 按应用授权；后台 RBAC 权限与 API Key scope 两套命名（见安全设计 §2.1） | P0 |
| FR-ADM-03 | 会话日志：按应用、时间、是否转人工、是否点踩筛选 | P0 |
| FR-ADM-04 | 审计日志：所有写操作（谁、何时、对象、前后差异、IP） | P0 |
| FR-ADM-05 | 仪表盘：对话量、拒答率、转人工率、点踩率、P50/P95 延迟、token 用量、意图分布；数据来自每日统计表 `app_daily_stats`（每小时刷新），不含调试与评测渠道 | P1 |
| FR-ADM-06 | 每条回答记录所用提示词版本（`prompt_version`），评测运行记录全部提示词版本 | P0 |
