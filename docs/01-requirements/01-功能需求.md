# 功能需求

优先级：P0 = v1 必须，P1 = v1 尽量，P2 = v2。

## 1. 应用管理（APP）
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-APP-01 | 创建/编辑/停用/删除应用。字段：名称、描述、头像、开场白、系统提示词、回答风格（简洁/详细/自定义）、兜底话术、语言 | P0 |
| FR-APP-02 | 检索参数：`vector_top_k`(默认20)、`keyword_top_k`(20)、`rerank_top_n`(5)、`rerank_threshold`(0.35)、`enable_rerank`、`history_turns`(6) | P0 |
| FR-APP-03 | 转人工规则：关键词命中（如"人工""投诉"）、连续 N 次拒答、可答性判断为否时是否转人工、转人工话术 | P0 |
| FR-APP-04 | 切块参数：`chunk_size`(500 token)、`chunk_overlap`(80)；修改后提示需重建索引 | P0 |
| FR-APP-05 | 应用级自定义词典（jieba），用于专有名词 | P1 |
| FR-APP-06 | 复制应用（含配置，不含文档） | P1 |

## 2. 知识库（KB）
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-KB-01 | 上传 PDF/DOCX/MD/TXT/HTML，单文件 ≤ 50MB，支持批量 | P0 |
| FR-KB-02 | 通过 URL 导入网页 | P0 |
| FR-KB-03 | 同应用内按 SHA-256 去重，重复上传返回已有文档 | P0 |
| FR-KB-04 | 状态 `queued → parsing → indexing → done / failed`，显示进度百分比与失败原因 | P0 |
| FR-KB-05 | 切块预览：序号、标题路径、正文、token 数；可搜索 | P0 |
| FR-KB-06 | 单文档重建、整个应用重建（配置变更后） | P0 |
| FR-KB-07 | 删除文档：立即不可检索，向量异步清理 | P0 |
| FR-KB-08 | 替换文档（新版本覆盖旧版本） | P1 |
| FR-KB-09 | 禁用单个切块（不删除，不参与检索） | P1 |

## 3. 问答（CHAT）
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-CHAT-01 | 多轮对话，按 `conversation_id` 续聊；无 ID 时新建 | P0 |
| FR-CHAT-02 | 阻塞与 SSE 流式两种模式 | P0 |
| FR-CHAT-03 | 回答带引用：文档 ID、文档名、标题路径、片段、分数 | P0 |
| FR-CHAT-04 | 检索不足时返回兜底话术，`answer_type=refused` | P0 |
| FR-CHAT-05 | 满足转人工规则时 `handoff=true` 并返回原因 | P0 |
| FR-CHAT-06 | 接入方可传 `user_id`（外部用户标识）与 `metadata` | P0 |
| FR-CHAT-07 | OpenAI 兼容接口 | P0 |
| FR-CHAT-08 | 调试模式（仅后台）：返回改写问题、各路检索结果、分数、耗时 | P0 |
| FR-CHAT-09 | 反馈：点赞/点踩 + 备注 | P0 |

## 4. 开放接口与 Key（KEY）
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-KEY-01 | 每个应用可建多个 Key；明文只在创建时显示一次 | P0 |
| FR-KEY-02 | Key 属性：名称、权限范围（`chat`、`kb:read`、`kb:write`）、RPM、日配额、过期时间、IP 白名单(P1) | P0 |
| FR-KEY-03 | 吊销立即生效；记录最近使用时间 | P0 |

## 5. 评测（EVAL）
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-EVAL-01 | 评测集 CRUD；用例：问题、期望答案、期望文档、是否应拒答、标签 | P0 |
| FR-EVAL-02 | CSV 导入导出 | P0 |
| FR-EVAL-03 | 运行评测（后台任务），记录当时的应用配置快照与指标 | P0 |
| FR-EVAL-04 | 两次运行对比，逐题看差异 | P1 |
| FR-EVAL-05 | 从点踩反馈生成用例 | P1 |

## 6. 用户、日志、审计（ADM）
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-ADM-01 | 登录（邮箱+密码）、修改密码、登录失败 5 次锁 15 分钟 | P0 |
| FR-ADM-02 | 角色：super_admin 全局；app_admin / viewer 按应用授权 | P0 |
| FR-ADM-03 | 会话日志：按应用、时间、是否转人工、是否点踩筛选 | P0 |
| FR-ADM-04 | 审计日志：所有写操作（谁、何时、对象、前后差异、IP） | P0 |
| FR-ADM-05 | 仪表盘：对话量、拒答率、转人工率、点踩率、平均延迟、token 用量 | P1 |
