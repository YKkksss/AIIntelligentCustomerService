# 技术选型

| 领域 | 选择 | 理由 | 备选 |
|---|---|---|---|
| 语言/包管理 | Python 3.12 + uv | LangChain 生态；uv 快、锁文件可复现 | poetry |
| Web 框架 | FastAPI | 异步、自动 OpenAPI、SSE 简单 | Litestar |
| SSE | 手写 `StreamingResponse`（`modules/chat/sse.py`：帧格式、15 秒心跳、断开检测） | 依赖少；事件顺序与断线落库逻辑已有测试（设计讨论 0009） | `sse-starlette` |
| 编排 | LangGraph | 固定流程 + 流式 + 状态可观测 | 纯 LangChain LCEL |
| ORM/迁移 | SQLAlchemy 2.0 async + asyncpg + Alembic | 成熟、类型友好 | SQLModel |
| 业务库 | PostgreSQL 16（复用） | 已有；全文检索内置 | MySQL（无向量、全文中文差） |
| 向量库 | Qdrant（共用 KnowledgeFlow 实例 v1.18，集合前缀 `aics_`；ADR-0002 修订） | 共享 PG 无 pgvector；Qdrant 轻量、过滤快、快照方便 | 给共享 PG 装 pgvector（会影响他人，见 ADR-0002） |
| 关键词检索 | PG FTS + jieba 预分词 | 无需新组件；`simple` 配置配合预分词即可中文检索 | Elasticsearch（内存大） |
| 任务队列 | Celery 5 + RabbitMQ（复用） | 见 ADR-0003 | ARQ / Dramatiq |
| 缓存/限流 | Redis（复用） | — | — |
| 对话模型 | DeepSeek（OpenAI 兼容） | 中文好、便宜 | 通义千问 |
| 向量/重排序 | 百炼 qwen3.7-text-embedding-flash / qwen3.7-text-rerank | 服务器无 GPU；中文效果好 | 本地 llama.cpp |
| 解析 | PyMuPDF、python-docx、trafilatura | 速度快、纯 Python 部署 | Unstructured（重） |
| 前端 | Vue 3 + Vite + TS + Element Plus + Pinia | 后台组件齐全、上手快 | React + AntD |
| 认证 | JWT（PyJWT）+ argon2（argon2-cffi） | 无状态；密码哈希业界推荐 | session |
| 加密 | `cryptography`（Fernet） | Webhook 签名密钥需可解密 | — |
| 上传解析 | `python-multipart` | FastAPI 表单 / 文件上传必需 | — |
| 时区 | `zoneinfo` + `tzdata` | 服务时间计算；Windows 无系统时区库 | pytz |
| 日志 | structlog（JSON） | 结构化、上下文绑定 | loguru |
| 指标 | prometheus-client | 标准 | OpenTelemetry（v2） |
| 追踪 | LangSmith / Langfuse（可选） | 调试 RAG | — |
| 质量 | ruff、import-linter、pytest、pytest-asyncio、pytest-cov、respx、pre-commit、gitleaks（mypy 计划渐进开启，尚未接入 CI） | — | — |
| 前端测试 | Vitest + @vue/test-utils（逻辑层覆盖率 ≥ 80%）、Playwright（里程碑冒烟） | 与 Vite 同生态 | Jest |

**引入时机**（未列出的已在 `backend/pyproject.toml`）：`python-multipart` M3.2；`openai`（dev 依赖，SDK 兼容测试）M3.3；`tzdata` M3.4；`cryptography` M3.5；PyJWT、argon2-cffi、前端 Vitest / openapi-typescript / `@microsoft/fetch-event-source` M4.1；ECharts M4.6；prometheus-client M6.3；k6 或 locust（不进依赖）M6.5。
