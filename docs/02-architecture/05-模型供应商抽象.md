# 模型供应商抽象

## 1. 接口
```python
class LLMProvider(Protocol):
    def chat_model(self, **overrides) -> BaseChatModel: ...   # LangChain 对象，便于 LangGraph 流式

class EmbeddingProvider(Protocol):
    model: str; dim: int
    async def embed_documents(self, texts: list[str]) -> list[list[float]]: ...
    async def embed_query(self, text: str) -> list[float]: ...

class RerankProvider(Protocol):
    model: str
    async def rerank(self, query: str, docs: list[str], top_n: int) -> list[tuple[int, float]]: ...
```
工厂 `get_llm(model: str | None)/get_embedder()/get_reranker()` 按 `AICS_*_PROVIDER` 选择实现；`get_llm` 的模型名必须存在于模型注册表。

## 1.1 模型注册表（`aics.core.models`）
- 来源：环境变量 `AICS_MODELS`（JSON 数组），启动时校验；`AICS_LLM_MODEL`、`AICS_EMBED_MODEL`、`AICS_RERANK_MODEL` 必须在其中，否则启动失败。
```json
[{"name":"deepseek-flash","kind":"chat","context_window":1000000,"price_in":2.0,"price_out":8.0},
 {"name":"qwen3.7-text-embedding-flash","kind":"embedding","context_window":8192,"price_in":0.125,"price_out":0},
 {"name":"qwen3.7-text-rerank","kind":"rerank","context_window":8192,"price_in":0.5,"price_out":0}]
```
- 字段：`name`（供应商模型名）、`kind`（`chat` / `embedding` / `rerank`）、`context_window`（token）、`price_in` / `price_out`（元 / 百万 token，仅用于用量估算展示，可为 0）。数值以供应商官方文档为准。`deepseek-flash` 已按 DeepSeek 官方价格表填写（上下文 1M；按高峰时段、缓存未命中保守取值：输入 2 元/百万 token、输出 8 元/百万 token；空闲时段与缓存命中更便宜，仅用于估算）；百炼向量 `qwen3.7-text-embedding-flash` 0.125 元/百万 token、重排 `qwen3.7-text-rerank` 0.5 元/百万 token。
- 用途：应用配置 `llm_model` / `summary_model` 只能选 `kind=chat` 的注册模型；保存时的 80% 窗口校验（[对话上下文管理 §9](07-对话上下文管理.md)）使用 `context_window`；`/admin/system/info` 与 `/admin/models` 返回注册表（不含密钥）。

## 2. 实现
| 类型 | provider 值 | 实现 | 说明 |
|---|---|---|---|
| LLM | `openai_compatible` | `ChatOpenAI(base_url, api_key, model)` | DeepSeek（默认 `deepseek-flash`）、本地 llama.cpp、其他兼容服务 |
| Embedding | `dashscope` | OpenAI 兼容模式 `POST {base}/embeddings`，`model=qwen3.7-text-embedding-flash`，`dimensions=1024` | qwen3.7-text-embedding-flash 支持多种维度，取 1024 平衡效果与内存 |
| Embedding | `openai_compatible` | 同上，任意兼容服务（llama.cpp `--embedding`） | |
| Rerank | `dashscope` | `POST https://dashscope.aliyuncs.com/api/v1/services/rerank/text-rerank/text-rerank`，body `{"model":"qwen3.7-text-rerank","input":{"query","documents"},"parameters":{"top_n":5}}` | gte-rerank 已于 2026-05-30 下线；备选 `gte-rerank-v2` |
| Rerank | `llamacpp` | llama.cpp `/v1/rerank` | 本地 Qwen3-Reranker |
| Rerank | `none` | 直接返回原顺序 | 关闭重排序 |

> 模型名、端点以阿里云百炼官方文档为准（2026-10 已核对），代码中不得硬编码。

## 3. 通用能力（装饰在所有实现外层）
- 超时：LLM 60s，embedding 20s，rerank 10s。
- 重试：429/5xx/网络错误指数退避（0.5s、1s），最多 2 次。
- 熔断：60s 内失败率 > 50% 且 ≥ 10 次 → 打开 30s。
- 计量：记录 token / 调用次数 / 耗时到 Prometheus 与 messages。
- 维度校验：embedding 返回维度 ≠ 配置维度 → 立刻报错，防止写入错误集合。

## 4. 实现说明（M2.2，2026-10-16）
- `providers/llm.py`：`OpenAICompatibleLLM.chat_model(**overrides)` 返回 LangChain `ChatOpenAI`（依赖 `langchain-openai`），只允许覆盖 `model`、`temperature`、`max_tokens`、`streaming`、`timeout`、`stop`；`model` 必须是注册表中 `kind=chat` 的模型。重试用 OpenAI SDK 自带指数退避（`max_retries=2`，与 §3 的 2 次一致），超时 `AICS_LLM_TIMEOUT_S`；流式调用无法套 `call_with_resilience`，熔断由 rag 节点层（M2.3）按整次节点调用计数。
- `providers/rerank.py`：`DashScopeReranker`（`input.documents` + `parameters.top_n`、`return_documents=false`）、`LlamaCppReranker`（`{query, documents, top_n}` → `results`）、`NoopReranker`（`none`，保持输入顺序，`is_noop=True`，分数不可与阈值比较）。返回 `[(index, score)]` 按分数降序、最多 `top_n` 条；响应中下标越界 / 重复 / 缺字段视为上游错误；单次最多 500 篇（DashScope 上限）。超时 10s、重试与熔断同 embedding。
- 工厂：`build_llm` / `build_reranker`（无缓存，便于测试）与 `get_llm` / `get_reranker`（进程单例）。
