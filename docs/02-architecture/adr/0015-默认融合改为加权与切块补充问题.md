# ADR-0015 默认融合改为加权（vector_weight=0.7）与切块补充问题
- 状态：已接受（2026-10-16）；修订 [ADR-0004](0004-混合检索与RRF.md) 的融合方式（RRF 改为可选，默认加权）
- 背景：M1 / M2.2b 评测（[M1 测试报告 §10](../../06-development/08-M1端到端测试报告.md)）中向量路明显强于全文路，RRF 等权融合 Hit@1 0.80 低于纯向量 0.88；设计讨论 [0003](../../09-design-discussions/0003-检索设置与切块补充问题落地（M2.2b）.md) 网格评测了融合方式、补充问题与重排。
- 决策：
  1. `rag_config.fusion` 默认 `weighted`、`vector_weight=0.7`（两路 min-max 归一后加权）；`rrf`（k=60）保留为选项；重排仍默认开启，是最主要的质量来源。
  2. 补充问题与切块同集合存储（payload `kind=question`、`chunk_id`），命中映射回切块；人工维护，不在入库时自动生成；重建时按正文哈希迁移，失配转待确认。
  3. 标签过滤在 Qdrant 与 PG 两侧同时生效。
- 后果：不重排或重排失败时 Hit@1 0.80 → 0.86（有补充问题 0.90）；min-max 归一对单路命中很少的问题敏感（单命中记 1.0），需在服务器真实样本上复核权重；补充问题需要运营投入。
