# ADR-0012 切块预设与父子切块
- 状态：已接受（2026-10-16，M1.3b）
- 背景：不同类型的知识（法规、合同、论文、FAQ、手册）对切分粒度要求差异大，单一 500/80 规则效果不稳定；短块检索准、但送给模型的上下文不完整，长块上下文完整、但检索被稀释。
- 决策：
  1. 切块预设放在配置文件 `backend/src/aics/rag/chunk_presets.yaml`，预设只是 `chunk_config` 的初始值；选择后仍可逐项修改，`preset` 字段只记录来源。切分逻辑只依赖展开后的字段（`strategy` 等），不依赖预设名。
  2. 自定义分隔符按字面量匹配，不开放正则（避免 ReDoS 与难以排查的配置错误）。
  3. 父子切块参照 Dify 父子分段与 LlamaIndex Parent Document Retriever：子块（默认 200 token）向量化与检索，父块（默认 1024 token，无重叠）送入模型；检索后按父块去重，rerank 在父块正文上进行。
  4. 父块存独立表 `chunk_parents`，`chunks.parent_id` 指向父块；chunks 仍然只存可检索单元，现有可检索条件、全文索引、Qdrant 点与 chunks 行一一对应不变。
  5. 80% 上下文窗口在父子模式下按 `parent_size` 计算。
- 后果：父子模式每个文档多写一张表、PG 存储增加约一倍正文；切换模式需重建索引（`chunk_config_version` +1）；评测需按应用比较两种模式。
