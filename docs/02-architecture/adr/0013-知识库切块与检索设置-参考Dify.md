# ADR-0013 知识库切块与检索设置（参考 Dify）
- 状态：已接受（2026-10-16）；讨论记录见[设计讨论 0001](../../09-design-discussions/0001-知识库切块与检索设置-参考Dify.md)
- 决策：
  1. 新增分块预览（不向量化）、预处理开关（合并空白、删除 URL/邮箱）、父块全文模式（按 token 上限分段，不丢内容）、父 / 子分隔符分开配置（M1.4）。
  2. 向量化文本加"文档标题 + 标题路径"前缀（上下文增强），切块正文保持原样；前缀由唯一函数生成，构建时使用的标题记入 `documents.indexed_title`（M1.4）。
  3. 检索模式（vector / fulltext / hybrid）、混合融合方式（rrf / weighted）、分数阈值、元数据过滤、切块补充问题、命中测试（M2.2b）；切块编辑、近重复检测、文档有效期（M4.3b）；切块质量统计（M4.6b）。
  4. 不做经济索引、LLM Q&A 分段、按字符计长度。
- 后果：配置项增多，统一由 `ChunkConfig` / `AppRagConfig` 校验并有默认值；分块大小继续以 token 为唯一口径。
