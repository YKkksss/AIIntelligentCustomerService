## 2. 组件职责
| 组件 | 职责 |
|---|---|
| aics-api | HTTP 接口（开放 + 管理）、鉴权、限流、RAG 在线问答（流式） |
| aics-worker | 文档入库、重建、向量清理、评测运行 |
| aics-beat | Celery 定时任务：清理过期会话缓存、软删除兜底清理、每日统计（与 worker 同镜像） |
| PostgreSQL | 业务数据、切块正文、全文检索（tsvector） |
| Qdrant | 切块向量 |
| Redis | 限流计数、缓存（应用配置、Key 校验结果）、Celery 结果、SSE 取消标志 |
| RabbitMQ | Celery 任务队列 |

## 3. 关键数据流
**入库**：上传 → API 保存文件、写 `documents(queued)` → 投递 `ingest_document` → Worker 解析、切块、分词、向量化 → 写 `chunks` 与 Qdrant → `done`。

**问答**：请求 → 鉴权/限流 → 加载应用配置（缓存）→ LangGraph 流程 → SSE 推送 → 落库 `messages`（异步不阻塞响应）。

## 4. 请求链路中的横切关注点
- `request_id` 中间件（读取或生成 `X-Request-ID`，写入日志与响应头）。
- 统一异常处理 → 统一错误体。
- 鉴权依赖：`require_api_key(scope)`、`require_user(role, app_id)`。
- 指标：请求耗时直方图、LLM token 计数、各 RAG 节点耗时。
