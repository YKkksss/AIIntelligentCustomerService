# 模块划分

后端采用"按业务模块分包 + 每个模块内分层"的结构：`router`（HTTP）→ `service`（业务）→ `repository`（数据库）。

| 模块 | 包 | 职责 | 主要依赖 |
|---|---|---|---|
| core | `aics.core` | 配置、日志、异常、安全工具（哈希、JWT）、依赖注入 | — |
| db | `aics.db` | 引擎、会话、Base、ORM 模型 | SQLAlchemy |
| auth | `aics.modules.auth` | 登录、刷新、用户、角色、应用授权 | core, db |
| apps | `aics.modules.apps` | 应用 CRUD、配置校验、配置缓存 | db, redis |
| apikeys | `aics.modules.apikeys` | Key 生成/校验/吊销、限流 | db, redis |
| knowledge | `aics.modules.knowledge` | 文档上传、列表、切块查询、重建与删除调度 | storage, tasks |
| ingest | `aics.ingest` | 解析器、切块器、分词、索引写入 | providers, vectorstore |
| rag | `aics.rag` | LangGraph 图、节点、提示词、检索器、引用处理 | providers, vectorstore, db |
| chat | `aics.modules.chat` | 对话接口、SSE、OpenAI 兼容层、会话与消息落库 | rag |
| feedback | `aics.modules.feedback` | 反馈 | db |
| eval | `aics.modules.eval` | 评测集、运行、指标计算 | rag, tasks |
| audit | `aics.modules.audit` | 审计写入（装饰器/依赖）与查询 | db |
| providers | `aics.providers` | LLM / Embedding / Rerank 抽象与实现 | httpx, langchain-openai |
| vectorstore | `aics.vectorstore` | Qdrant 封装 | qdrant-client |
| storage | `aics.storage` | 文件存储接口与本地实现 | — |
| tasks | `aics.tasks` | Celery app 与任务定义 | 以上各模块 service |

**依赖规则**：模块之间只通过 `service` 调用；`router` 不直接访问 `repository`；`rag`/`ingest` 不依赖 FastAPI（可在 worker、脚本、测试中复用）。
