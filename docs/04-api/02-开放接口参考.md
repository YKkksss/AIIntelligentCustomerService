# 开放接口参考（API Key）

所有示例：`BASE=http://localhost:8000`，`KEY=aics_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`，`APP=0192f0c1-...`。

## 1. 对话
### POST /api/v1/apps/{app_id}/chat
scope：`chat`

请求：
```json
{
  "question": "退货要多久到账？",
  "conversation_id": null,
  "user_id": "u_10086",
  "stream": false,
  "metadata": {"channel": "app"}
}
```
| 字段 | 必填 | 说明 |
|---|---|---|
| question | 是 | 1–2000 字 |
| conversation_id | 否 | 续聊时传；不传则新建 |
| user_id | 否 | 接入方用户标识，≤ 128 字符 |
| stream | 否 | 默认 false |
| metadata | 否 | ≤ 4KB，原样存储 |

阻塞响应 200：
```json
{
  "conversation_id": "0192f0d2-...",
  "message_id": "0192f0d2-...",
  "answer": "退货审核通过后，款项会在 3–5 个工作日原路退回 [1]。",
  "answer_type": "answer",
  "handoff": false,
  "handoff_reason": null,
  "citations": [
    {"n": 1, "document_id": "0192...", "document_title": "售后政策.pdf",
     "heading_path": "售后政策 > 退款 > 到账时间", "snippet": "审核通过后 3-5 个工作日原路退回……",
     "score": 0.82, "page": 3}
  ],
  "usage": {"prompt_tokens": 1830, "completion_tokens": 64, "total_tokens": 1894},
  "latency_ms": 2310
}
```
`answer_type`：`answer`（正常回答）、`refused`（知识库无答案，`answer` 为兜底话术）、`handoff`（需转人工，`answer` 为转人工话术）。

### 流式（stream=true）
响应 `Content-Type: text/event-stream`，事件依次为：
```
event: start
data: {"conversation_id":"0192f0d2-...","message_id":"0192f0d2-..."}

event: citations
data: {"citations":[{"n":1,"document_id":"...","document_title":"售后政策.pdf","heading_path":"售后政策 > 退款 > 到账时间","snippet":"...","score":0.82,"page":3}]}

event: delta
data: {"text":"退货审核通过后，"}

event: delta
data: {"text":"款项会在 3–5 个工作日原路退回 [1]。"}

event: end
data: {"answer_type":"answer","handoff":false,"handoff_reason":null,"used_citations":[1],"usage":{"prompt_tokens":1830,"completion_tokens":64,"total_tokens":1894},"latency_ms":2310}
```
- 拒答 / 转人工时：没有 `citations`，`delta` 一次性给出话术，`end.answer_type` 为 `refused`/`handoff`。
- 出错：`event: error`，`data: {"code":"UPSTREAM_TIMEOUT","message":"...","request_id":"..."}`，随后关闭。
- `citations` 事件是"候选来源"；最终实际引用以 `end.used_citations` 为准。
- 心跳：`: ping` 注释行，客户端忽略即可。

### GET /api/v1/apps/{app_id}/conversations/{conversation_id}/messages
scope：`chat`。返回该会话消息（游标分页），用于接入方回显历史。

## 2. 反馈
### POST /api/v1/apps/{app_id}/messages/{message_id}/feedback
```json
{"rating": -1, "comment": "到账时间说错了"}
```
响应 200：`{"id":"...","rating":-1}`。重复提交覆盖。

## 3. OpenAI 兼容
### GET /v1/models
返回该 Key 对应的应用：`{"object":"list","data":[{"id":"<app_id>","object":"model","owned_by":"aics"}]}`

### POST /v1/chat/completions
```json
{
  "model": "<app_id>",
  "messages": [
    {"role": "user", "content": "退货要多久到账？"},
    {"role": "assistant", "content": "……"},
    {"role": "user", "content": "那运费谁出？"}
  ],
  "stream": false,
  "user": "u_10086"
}
```
- 最后一条 `user` 消息为问题，之前的作为历史（最多取 `history_turns` 轮）。客户端传的 `system` 消息**忽略**（应用配置为准，防止绕过规则）。
- `temperature`、`max_tokens` 可传，受应用配置上限约束；`tools` 等不支持的字段忽略。
- `model` 与 Key 所属应用不一致 → `404 model_not_found`（OpenAI 风格错误体 `{"error":{"message","type","code"}}`）。

响应：
```json
{
  "id": "chatcmpl-0192f0d2...",
  "object": "chat.completion",
  "created": 1792000000,
  "model": "<app_id>",
  "choices": [{"index": 0, "message": {"role": "assistant", "content": "运费由……[1]"}, "finish_reason": "stop"}],
  "usage": {"prompt_tokens": 1900, "completion_tokens": 50, "total_tokens": 1950},
  "aics": {"message_id": "...", "conversation_id": "...", "answer_type": "answer", "handoff": false, "citations": [ ... ]}
}
```
流式：标准 `data: {"object":"chat.completion.chunk",...}`，最后一个 chunk 在 `aics` 字段中带 `citations`、`answer_type`，然后 `data: [DONE]`。

## 4. 知识库
| 方法 | 路径 | scope | 说明 |
|---|---|---|---|
| POST | `/api/v1/apps/{app_id}/documents` | kb:write | multipart：`file`、`title?`、`metadata?`(JSON 字符串) |
| POST | `/api/v1/apps/{app_id}/documents/url` | kb:write | `{"url":"https://...","title":null}` |
| GET | `/api/v1/apps/{app_id}/documents` | kb:read | `?status=done&q=关键字&page=1` |
| GET | `/api/v1/apps/{app_id}/documents/{document_id}` | kb:read | 含 status、progress、error、chunk_count |
| GET | `/api/v1/apps/{app_id}/documents/{document_id}/chunks` | kb:read | 分页 |
| POST | `/api/v1/apps/{app_id}/documents/{document_id}/reindex` | kb:write | 202 |
| DELETE | `/api/v1/apps/{app_id}/documents/{document_id}` | kb:write | 204 |

上传响应 202：
```json
{"id":"0192...","title":"售后政策.pdf","status":"queued","progress":0,"duplicate":false,"job_id":"0192..."}
```
重复文件 200 + `"duplicate": true`，返回已有文档。

文档对象：
```json
{"id":"...","title":"售后政策.pdf","source_type":"file","mime_type":"application/pdf","size_bytes":523441,
 "status":"done","progress":100,"error":null,"chunk_count":42,"metadata":{},
 "created_at":"2026-10-14T17:00:00+08:00","updated_at":"2026-10-14T17:01:30+08:00"}
```

## 5. 健康检查（无需鉴权）
- `GET /healthz` → `{"status":"ok"}`（进程存活）
- `GET /readyz` → `{"status":"ok","checks":{"postgres":"ok","redis":"ok","rabbitmq":"ok","qdrant":"ok"}}`；任一失败返回 503。
