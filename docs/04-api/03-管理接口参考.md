# 管理接口参考（JWT，前缀 `/api/v1/admin`）

权限列：S = super_admin，A = 该应用 app_admin，V = 该应用 viewer。

## 认证
| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/auth/login` | 公开 | `{"email","password"}` → `{"access_token","refresh_token","expires_in":1800,"user":{...}}` |
| POST | `/auth/refresh` | 公开 | `{"refresh_token"}` → 新的一对 token |
| POST | `/auth/logout` | 登录 | 吊销 refresh（Redis 黑名单） |
| GET | `/auth/me` | 登录 | 当前用户 + 各应用角色 |
| POST | `/auth/change-password` | 登录 | `{"old_password","new_password"}`（≥ 10 位，含字母数字） |

## 用户与授权
| 方法 | 路径 | 权限 |
|---|---|---|
| GET/POST | `/users` | S |
| GET/PATCH/DELETE | `/users/{user_id}` | S |
| POST | `/users/{user_id}/reset-password` | S（返回一次性临时密码） |
| GET | `/apps/{app_id}/members` | S, A |
| PUT | `/apps/{app_id}/members/{user_id}` | S, A（`{"role":"app_admin"|"viewer"}`；不能移除或降级该应用最后一个 app_admin） |
| DELETE | `/apps/{app_id}/members/{user_id}` | S, A |

## 应用
| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/apps` | 登录 | 只返回有权限的应用 |
| POST | `/apps` | S | 创建，带默认配置 |
| GET | `/apps/{app_id}` | S,A,V | |
| PATCH | `/apps/{app_id}` | S,A | 部分更新；若 `chunk_config` 变化，响应 `{"reindex_required":true}` |
| POST | `/apps/{app_id}/copy` | S | |
| DELETE | `/apps/{app_id}` | S | 软删除，吊销全部 Key，异步清理 |
| POST | `/apps/{app_id}/reindex` | S,A | 全量重建，返回 job |

## 知识库（与开放接口相同的功能，前缀不同）
`/apps/{app_id}/documents...`（S,A 写；V 读），另加：
| 方法 | 路径 | 说明 |
|---|---|---|
| PATCH | `/apps/{app_id}/chunks/{chunk_id}` | `{"enabled":false}` 禁用切块 |
| GET | `/apps/{app_id}/jobs` | 后台任务列表与进度 |

## 调试对话
| 方法 | 路径 | 权限 |
|---|---|---|
| POST | `/apps/{app_id}/debug/chat` | S,A,V |

请求同开放对话接口，额外 `"overrides": {"rag_config": {...}}`（临时覆盖参数试效果，不保存）。SSE 额外事件：
```
event: trace
data: {"rewritten_query":"退货运费由谁承担","vector_hits":[{"chunk_id":"...","score":0.71,"rank":1}],
       "keyword_hits":[...],"fused":[...],
       "reranked":[{"chunk_id":"...","document_title":"售后政策.pdf","heading_path":"...","text":"...","rerank_score":0.82}],
       "decision":"answer","decision_reason":"top rerank 0.82 >= 0.35","degraded":[],
       "timings":{"condense":420,"retrieve":180,"rerank":160,"judge":0,"generate_first_token":610}}
```
会话 `channel=debug`，不计入对外统计。

## API Key
| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/apps/{app_id}/api-keys` | S,A | 只返回 prefix，不返回明文 |
| POST | `/apps/{app_id}/api-keys` | S,A | `{"name","scopes","rpm_limit","daily_quota","expires_at"}` → 响应含 `"key":"aics_..."`（仅此一次） |
| PATCH | `/apps/{app_id}/api-keys/{key_id}` | S,A | 改名称、限额 |
| POST | `/apps/{app_id}/api-keys/{key_id}/revoke` | S,A | |

## 会话与反馈
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/apps/{app_id}/conversations` | 筛选：`channel`、`handoff`、`has_negative_feedback`、`from`、`to`、`q`；游标分页 |
| GET | `/apps/{app_id}/conversations/{id}` | 含全部消息、引用、trace |
| GET | `/apps/{app_id}/feedback` | `?rating=-1&handled=false` |
| PATCH | `/apps/{app_id}/feedback/{id}` | `{"handled":true}` |

## 评测
| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/apps/{app_id}/eval-sets` | |
| GET/PATCH/DELETE | `/apps/{app_id}/eval-sets/{set_id}` | |
| GET/POST | `/apps/{app_id}/eval-sets/{set_id}/cases` | |
| PATCH/DELETE | `/apps/{app_id}/eval-sets/{set_id}/cases/{case_id}` | |
| POST | `/apps/{app_id}/eval-sets/{set_id}/import` | CSV：`question,expected_answer,expected_documents,should_refuse,tags` |
| GET | `/apps/{app_id}/eval-sets/{set_id}/export` | CSV |
| POST | `/apps/{app_id}/eval-sets/{set_id}/runs` | `{"overrides":{...}}` → 202 run |
| GET | `/apps/{app_id}/eval-runs/{run_id}` | 指标 + 进度 |
| GET | `/apps/{app_id}/eval-runs/{run_id}/results` | 逐题结果 |
| GET | `/apps/{app_id}/eval-runs/compare?a=&b=` | 对比 |
| POST | `/apps/{app_id}/feedback/{id}/to-eval-case` | `{"eval_set_id","expected_answer"}` |

## 审计与仪表盘
| 方法 | 路径 | 权限 |
|---|---|---|
| GET | `/audit-logs?app_id=&actor_id=&action=&from=&to=` | S（全部）；A（本应用） |
| GET | `/apps/{app_id}/stats?from=&to=&granularity=day` | S,A,V → 对话数、拒答率、转人工率、点踩率、P50/P95 延迟、token |
| GET | `/system/info` | S → 版本、模型配置（不含密钥）、依赖状态 |
