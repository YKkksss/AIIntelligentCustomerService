# 管理接口参考（JWT，前缀 `/api/v1/admin`）

权限列：S = super_admin，A = 该应用 app_admin，V = 该应用 viewer。每个接口在代码中用 `require_perm("<RBAC 权限名>")` 声明，角色与权限的映射见[安全设计 §2.1](../08-security/01-安全设计.md)；本表的 S/A/V 是该映射的展开结果。

## 认证
| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/auth/login` | 公开 | `{"email","password"}` → `{"access_token","refresh_token","expires_in":1800,"user":{...}}` |
| POST | `/auth/refresh` | 公开 | `{"refresh_token"}` → 新的一对 token |
| POST | `/auth/logout` | 登录 | 吊销 refresh（Redis 黑名单） |
| GET | `/auth/me` | 登录 | 当前用户 + 各应用角色 |
| POST | `/auth/change-password` | 登录 | `{"old_password","new_password"}`（≥ 10 位，含字母数字） |

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/apps` | 登录 | 只返回有权限的应用 |

| GET | `/apps/{app_id}` | S,A,V | |
| PATCH | `/apps/{app_id}` | S,A | 部分更新；`rag_config` 用 `AppRagConfig` 校验（失败 422）；若 `chunk_config` 变化，响应 `{"reindex_required":true}`（`chunk_config_version` +1，需手动触发重建；有文档级 `chunk_config` 的文档不受影响、不需重建）；若 `custom_dict` 变化，自动投递 `retokenize_app` 并在响应中返回 `{"retokenize_job_id":"..."}` |
| POST | `/apps/{app_id}/copy` | S | |
| DELETE | `/apps/{app_id}` | S | `status='deleting'`，立即吊销全部 Key、关闭全部会话，投递 `cleanup_app`（202 返回 job）；进行中的入库/评测/压缩任务检查到 deleting 后中止（job `cancelled`） |
| POST | `/apps/{app_id}/reindex` | S,A | 全量重建（`reindex_app`），返回 job；默认跳过有文档级 `chunk_config` 的文档（结果 `skipped_override`），`{"include_overridden":true}` 时一并重建 |
| GET | `/chunk-presets` | 登录 | 切块预设列表 `[{name, label, description, config}]`（`config` 为展开后的完整 chunk_config，前端一键填充后可修改）；PATCH 时 `chunk_config` 含 `preset` 则以该预设为底再叠加其他键 |
| GET | `/models` | 登录 | 模型注册表（`AICS_MODELS`）：`[{name, kind, context_window}]`，供配置页选择 `llm_model` / `summary_model` |

## 知识库（与开放接口相同的功能，前缀不同）
`/apps/{app_id}/documents...`（S,A 写；V 读），另加：
| 方法 | 路径 | 说明 |
|---|---|---|
| PATCH | `/apps/{app_id}/documents/{document_id}` | `{"title","metadata"}`（S,A）；M2.2b 起含 `tags`，M4.3b 起含 `effective_at`/`expires_at`。M1.7 起可含 `chunk_config`（部分键或 `preset`；`null` = 恢复跟随应用）：生效配置变化时只重建该文档并返回 `{"job_id":"..."}`，否则 200 无任务（规则见[文档处理流水线 §3.5](../02-architecture/04-文档处理流水线.md)） |
| POST | `/apps/{app_id}/documents/preview` | 分块预览（S,A,V）：multipart `file` + 可选 `chunk_config`（JSON，临时值）；只解析与切块，不向量化、不写库，返回前 `limit`（默认 50，≤ 200）条（M1.4 服务，M4.3 页面） |
| GET | `/apps/{app_id}/documents/{document_id}/preview?limit=` | 用该文档生效的（文档级覆盖，否则应用当前）或请求体给出的临时切块配置预览已上传文档 |
| POST | `/apps/{app_id}/documents`、`/documents/url`、`PUT .../file`、`POST .../reindex` | 后台版本均可多带 `chunk_config`（JSON；上传 / 导入合并到应用配置，替换 / 重建合并到文档当前生效配置）与 `reset_chunk_config`（替换 / 重建），校验失败 `422 VALIDATION_ERROR`（M1.7 服务，M4.3 接入） |
| POST | `/apps/{app_id}/hit-test` | 命中测试（S,A,V）：`{"query","overrides":{"rag_config":{...}},"filters":{"tags":[]}}`，返回两路命中、融合、rerank 顺序与分数（M2.2b） |
| POST | `/apps/{app_id}/chunks` | 手工新增切块（S,A，M4.3b） |
| PUT | `/apps/{app_id}/chunks/{chunk_id}/text` | 修改切块正文，只重新向量化该切块（S,A，M4.3b） |
| GET/PUT | `/apps/{app_id}/chunks/{chunk_id}/questions` | 切块补充问题（S,A，M2.2b） |
| PUT | `/apps/{app_id}/documents/{document_id}/file` | 替换文档（S,A），规则同开放接口 |
| GET | `/apps/{app_id}/chunks?review_status=flagged&document_id=` | 切块查询（S,A,V）；`review_status=flagged` 即"待复核切块"列表，含 `flag_reason` |
| PATCH | `/apps/{app_id}/chunks/{chunk_id}` | （S,A）`{"enabled":false}` 禁用切块；`{"review_status":"approved"}` 复核通过（恢复可检索）；复核为恶意时用 `{"enabled":false}`。均写审计并同步 Qdrant payload |
| GET | `/apps/{app_id}/jobs` | 后台任务列表与进度（S,A,V），`?type=&status=` |

## 调试对话
| 方法 | 路径 | 权限 |
|---|---|---|
| POST | `/apps/{app_id}/debug/chat` | S,A,V |
