# 第三方接入指南

## 1. 接入步骤
1. 找平台管理员创建应用并上传资料（或自己用 `kb:write` Key 通过接口上传）。
2. 在后台「API Key」页创建 Key，**立即复制保存**（只显示一次），记下应用 ID。
3. 用下面的示例调通，再接入你的系统。
4. **Key 只放在服务端**，不要写进网页或 App 安装包。浏览器需要直接调用时，请经你自己的后端转发。

## 2. curl
```bash
export AICS_BASE=http://192.168.110.86:8080
export AICS_KEY=aics_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
export AICS_APP=<app_id>

# 阻塞
curl -s "$AICS_BASE/api/v1/apps/$AICS_APP/chat" \
  -H "Authorization: Bearer $AICS_KEY" -H "Content-Type: application/json" \
  -d '{"question":"退货要多久到账？","user_id":"u_10086"}'

# 流式（-N 关闭缓冲）
curl -N "$AICS_BASE/api/v1/apps/$AICS_APP/chat" \
  -H "Authorization: Bearer $AICS_KEY" -H "Content-Type: application/json" \
  -d '{"question":"退货要多久到账？","stream":true}'

# 上传资料
curl -s "$AICS_BASE/api/v1/apps/$AICS_APP/documents" \
  -H "Authorization: Bearer $AICS_KEY" -H "Idempotency-Key: $(uuidgen)" \
  -F "file=@售后政策.pdf"
```

## 3. Python（httpx，原生接口 + 流式）
```python
import json, os, httpx

BASE, KEY, APP = os.environ["AICS_BASE"], os.environ["AICS_KEY"], os.environ["AICS_APP"]
headers = {"Authorization": f"Bearer {KEY}"}

def ask(question: str, conversation_id: str | None = None) -> dict:
    r = httpx.post(f"{BASE}/api/v1/apps/{APP}/chat", headers=headers, timeout=60,
                   json={"question": question, "conversation_id": conversation_id})
    r.raise_for_status()
    return r.json()

def ask_stream(question: str):
    with httpx.stream("POST", f"{BASE}/api/v1/apps/{APP}/chat", headers=headers, timeout=60,
                      json={"question": question, "stream": True}) as r:
        r.raise_for_status()
        event = None
        for line in r.iter_lines():
            if line.startswith("event:"):
                event = line[6:].strip()
            elif line.startswith("data:"):
                data = json.loads(line[5:])
                if event == "delta":
                    print(data["text"], end="", flush=True)
                elif event == "end":
                    print("\n", data)
                elif event == "error":
                    raise RuntimeError(data)

res = ask("退货要多久到账？")
print(res["answer"], res["citations"])
if res["handoff"]:
    ...  # 转给你们的人工客服系统
ask("那运费谁出？", res["conversation_id"])  # 续聊
```

## 4. Python（OpenAI SDK，零改造接入）
```python
from openai import OpenAI
client = OpenAI(base_url="http://192.168.110.86:8080/v1", api_key="aics_xxx")
resp = client.chat.completions.create(model="<app_id>",
    messages=[{"role": "user", "content": "退货要多久到账？"}])
print(resp.choices[0].message.content)
print(resp.model_extra["aics"]["citations"])   # 引用在扩展字段

for chunk in client.chat.completions.create(model="<app_id>", stream=True,
        messages=[{"role": "user", "content": "退货要多久到账？"}]):
    print(chunk.choices[0].delta.content or "", end="")
```
LangChain 中：`ChatOpenAI(base_url=".../v1", api_key="aics_xxx", model="<app_id>")`。

## 5. JavaScript / Node 18+（fetch 读取 SSE）
```js
const res = await fetch(`${BASE}/api/v1/apps/${APP}/chat`, {
  method: "POST",
  headers: { Authorization: `Bearer ${KEY}`, "Content-Type": "application/json" },
  body: JSON.stringify({ question: "退货要多久到账？", stream: true }),
});
const reader = res.body.pipeThrough(new TextDecoderStream()).getReader();
let buf = "";
for (;;) {
  const { value, done } = await reader.read();
  if (done) break;
  buf += value;
  let i;
  while ((i = buf.indexOf("\n\n")) >= 0) {        // 事件以空行分隔
    const raw = buf.slice(0, i); buf = buf.slice(i + 2);
    const ev = /^event: (.*)$/m.exec(raw)?.[1];
    const data = /^data: (.*)$/m.exec(raw)?.[1];
    if (!data) continue;                          // 心跳
    const obj = JSON.parse(data);
    if (ev === "delta") process.stdout.write(obj.text);
    if (ev === "end") console.log("\n", obj);
  }
}
```
> 浏览器原生 `EventSource` 只支持 GET，不能带 Authorization 头，所以使用 fetch 方式（或 `@microsoft/fetch-event-source`）。

## 6. 接入建议
- **处理三种 answer_type**：`answer` 正常展示并显示引用；`refused` 展示话术并提供"转人工"按钮；`handoff` 直接转你的人工系统。
- **重试**：仅对 429（按 `Retry-After`）、502/503/504 重试，最多 2 次；400/401/403/404 不要重试。
- **会话**：保存 `conversation_id` 与你的用户会话关联；会话 24 小时无活动后建议新建。
- **反馈**：把用户的赞/踩回传，帮助我们改进准确率。
- 出问题时把响应头 `X-Request-ID` 发给管理员。
