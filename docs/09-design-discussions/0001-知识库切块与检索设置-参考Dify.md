# 0001 知识库切块与检索设置（参考 Dify）
- 日期：2026-10-16
- 参与：项目负责人（评审 Dify 知识库设置截图）、开发
- 相关：[ADR-0012 切块预设与父子切块](../02-architecture/adr/0012-切块预设与父子切块.md)、[ADR-0013](../02-architecture/adr/0013-知识库切块与检索设置-参考Dify.md)

## 1. 背景
负责人评审了 Dify 知识库的设置界面，主要内容：
- **通用分段**：分隔符 `\n`、最大长度 1024 **字符**、重叠 50；预处理开关"替换连续空格 / 换行 / 制表符""删除所有 URL 和电子邮件地址"；自动摘要；Q&A 分段（LLM 生成问答对）。
- **父子分段**：父块"段落"模式（分隔符 `\n\n`、1024）或"全文"模式（整篇文档为父块，超过 10000 token 截断）；子块分隔符 `\n`、512。
- **索引方式**：高质量（向量）与经济（只用关键词，每块 10 个关键词，不支持父子分段）。
- **检索设置**：向量 / 全文 / 混合三选一，各自可开关 rerank、Top K、分数阈值；混合检索可选"权重设置"或"Rerank 模型"。
- **分块预览**按钮。

AICS 在此之前已有：按 token 的切块与预设（M1.3b）、父子切块、PG 全文 + 向量混合检索 + RRF + rerank（ADR-0004）。

## 2. 借鉴（ADOPT）
| # | 内容 | 收益 | 落地 |
|---|---|---|---|
| A1 | **分块预览接口**：用当前（或临时）切块配置对文件做解析 + 切块并返回结果，不调用向量化 | 调参不花钱、不污染索引；管理员能直观看到预设效果 | M1.4（服务方法），M4.3 页面 |
| A2 | **文本预处理开关**：合并连续空白、删除 URL / 邮箱 | 减少噪声 token，避免把链接、邮箱当作语义内容；对网页导入效果明显 | M1.4 |
| A3 | **父块"全文"模式**（带 token 上限） | 短文档（制度、公告、产品说明）整体作为上下文，回答更完整 | M1.4 |
| A4 | **父块与子块分别设置分隔符** | 父块按段落、子块按行这类常见组合可直接配置 | M1.4 |
| A5 | **可选检索模式**：向量 / 全文 / 混合；混合时可选权重融合或 rerank；`top_k`、分数阈值作为应用配置 | 不同知识库（编号密集 vs 语义问答）可以选更合适的检索方式；阈值可按评测校准 | M2.2b |

## 3. 不借鉴（NOT ADOPT）
| # | 内容 | 理由 |
|---|---|---|
| N1 | **经济索引**（只用关键词、每块 10 个关键词） | 我们已有 PG 全文检索作为关键词通道与向量失败时的兜底；向量化成本极低（0.125 元 / 百万 token），省下的钱不值得牺牲召回质量与配置复杂度 |
| N2 | **LLM 生成 Q&A 分段** | 入库时逐块调用 LLM，成本与耗时高且不稳定；FAQ 类知识用 `faq` 预设按原文问答对切分即可；"同义问法"需求由我们的补充 C4 覆盖 |
| N3 | **按字符计的分块长度** | 我们统一用 token（`core.tokens`），与模型窗口校验、上下文预算、成本一致；中英文字符与 token 比例差异大，按字符会导致窗口估算失真。前端可显示"约 N 字"的换算提示 |

## 4. 我们的补充（OUR ADDITIONS）
| # | 内容 | 收益 | 落地 |
|---|---|---|---|
| C1 | **上下文增强向量化**：向量化文本前缀"文档标题 + 标题路径"（Anthropic Contextual Retrieval 的思路，不调用 LLM） | 孤立切块（如"运费由商家承担"）带上"售后政策 > 退货规则"后语义更完整，召回率提升，成本几乎为零 | M1.4 |
| C2 | **文档 / 切块元数据标签 + 过滤检索** | 同一应用内按产品线、地区、渠道等限定检索范围，避免串答 | M2.2b |
| C3 | **单个切块的人工编辑 / 禁用 / 新增**，只重新向量化该切块 | 发现错误时无需重建整个文档；运营可补充遗漏知识 | M4.3b |
| C4 | **切块补充问题**（同义问法，单独向量化，命中后返回原切块） | 用户问法与文档措辞差异大时显著提升召回；人工维护，可控 | M2.2b |
| C5 | **命中测试**：输入问题，返回召回切块、各路分数、rerank 顺序 | 管理员自助排查"为什么没答上来"，配合阈值校准 | M2.2b（服务），M4.3b（页面） |
| C6 | **入库近重复检测** | 同一内容的多个版本（如新旧政策）并存会导致矛盾回答；入库时提示 | M4.3b |
| C7 | **文档生效 / 失效时间**：失效后不参与检索 | 活动规则、限时政策到期自动下线，避免过期答案 | M4.3b |
| C8 | **切块质量统计**：召回次数、被引用次数、关联点赞 / 点踩，标记长期未命中或差评集中的切块 | 知识库运营有数据依据，定位过时 / 错误切块 | M4.6b |

## 5. 最终决策
- 采纳 A1–A5、C1–C8，不采纳 N1–N3；决策摘要见 ADR-0013。
- 落地顺序：M1.4（A1–A4、C1）→ M2.2b（A5、C2、C4、C5 服务）→ M4.3b（C3、C5 页面、C6、C7）→ M4.6b（C8）。
