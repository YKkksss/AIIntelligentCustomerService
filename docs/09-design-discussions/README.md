# 设计讨论记录（Design Discussions）

本目录记录每一次重要的设计讨论，供后来的开发者学习与评审"为什么是现在这样"。与 ADR 的分工：

| | 设计讨论记录（本目录） | ADR（`02-architecture/adr/`） |
|---|---|---|
| 内容 | 讨论的完整上下文：参考了谁、借鉴了什么及原因、**刻意不照搬**什么及原因、我们自己的补充 | 最终决策本身（一页内） |
| 粒度 | 一次讨论一篇，可产生 0–N 个 ADR | 一个决策一篇 |
| 修改 | 只追加"后续"小节，不改写历史结论 | 被取代时标记"已取代" |

## 约定
- **今后所有设计讨论都必须在此记录**（包括参考竞品 / 开源项目 / 论文后的取舍），并在同一提交中把结论同步到相关设计文档与开发计划。
- 文件名：`NNNN-主题.md`（四位序号，从 0001 起）。
- 固定结构：背景 → 借鉴（收益 + 落地里程碑）→ 不借鉴（理由）→ 我们的补充（收益 + 落地里程碑）→ 最终决策 → 同步到的文档 → 后续。
- 每条结论必须写明落地的里程碑子步骤（如 M1.4、M2.2b），未排期的写"待定"并说明触发条件。
