# 参数默认值与依据

> 本文是系统可调参数**默认值的唯一来源**：每项列出当前默认值、依据（测试报告章节 / 指标）、确定日期与是否待服务器复验。代码（`backend/src/aics/rag/config.py`、`rag/chunk_presets.yaml`）与设计文档中的默认值必须与本表一致；改默认值先改本表。

## 常设规则
**每轮测试 / 评测结束后**：① 把结果写入 `docs/06-development/` 下的测试报告；② 把测试支持的最佳取值采纳为系统默认值，同步更新本表、代码、设计文档与测试；③ 测试没有覆盖或不支持的参数不改，保持原设计值并标注“未评测”；④ 只在开发机 / 合成数据上得到的结论标注“待服务器复验”，复验后更新日期与依据。
