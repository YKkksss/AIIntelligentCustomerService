# 编码规范

## Python
- 格式与检查：ruff（`line-length=100`，规则 `E,F,I,UP,B,SIM,ASYNC,S`；行宽由 `ruff format` 保证，E501 不单独检查以免中文注释被迫折行），`ruff format`。类型：全部公开函数写类型注解，mypy 渐进开启（先 `core/ rag/ providers/`）。
- 命名：模块/函数 `snake_case`，类 `PascalCase`，常量 `UPPER_CASE`。
- 异步：I/O 一律 `async`；禁止在 async 函数里调用阻塞库（PyMuPDF 等解析只在 worker 同步执行）。
- 分层：router 只做参数与响应；业务在 service；SQL 在 repository。模块依赖方向遵守[模块划分 §3](../02-architecture/02-模块划分.md)（import-linter 在 CI 中检查）：`rag` 不 import `db` / `modules` / FastAPI；Celery 任务只调用 service。
- 每个查询必须带 `app_id`：带 `app_id` 的表的 repository 继承 `AppScopedRepository`，方法签名第一个参数为 `app_id`。
- token 计数只用 `aics.core.tokens.count_tokens`；中文分词只用 `aics.core.textsearch.get_tokenizer(app_id, ...)`（禁止 `jieba.load_userdict` / `jieba.add_word` 修改全局词典）；tsquery 只用 `build_tsquery`。
- 应用配置结构只在 `aics/rag/config.py` 定义，其他地方引用该 schema，不重复定义字段。
- 异常：抛 `AppError(code, message, status)` 子类，不要返回错误字典。
- 配置：只从 `core.config.settings` 读取，不直接 `os.environ`。
- 日志：`log = structlog.get_logger()`；`log.info("document.parsed", document_id=..., chunks=...)`，事件名用 `模块.动作`；**禁止记录密钥、密码、完整 API Key、用户问题全文以外的个人信息**。
- 注释：中文；解释"为什么"，不复述代码。docstring 用于公开函数（也会被 LangChain 工具读取的地方要写准确）。
- 提示词只放在 `*/prompts/*.md` 文件（`rag/prompts/`、`memory/prompts/`、`modules/eval/prompts/`），带 YAML front-matter（`name`、`version`）；修改正文必须 +1 `version`（CI 校验），不在代码中写提示词常量。

## TypeScript / Vue
- ESLint + Prettier；`<script setup lang="ts">`；组件 `PascalCase.vue`。
- 接口类型来自生成的 `schema.d.ts`，不手写重复类型。
- 不在前端存储 API Key 明文（仅创建时展示）。

## 通用
- 文件 UTF-8 无 BOM，LF 换行（`.gitattributes` 设置 `* text=auto eol=lf`）。
- 不提交真实业务资料、真实客户数据、密钥。测试数据使用虚构内容。
