# 项目目录结构

> M0 已按此创建骨架（空包只含说明性 `__init__.py`，随里程碑填充）；标注 M1+ 的文件尚未创建。

```
AIIntelligentCustomerService/
├─ README.md / .gitignore / .env.example / LICENSE / CHANGELOG.md
├─ .pre-commit-config.yaml / .gitleaks.toml
├─ .github/
│  ├─ workflows/ci.yml          # gitleaks + 后端（ruff、import-linter、提示词版本、pytest+覆盖率）+ 前端（lint、build）；push dev / PR
│  ├─ workflows/release.yml     # 打 tag vX.Y.Z 时构建镜像、生成 Release（M6）
│  └─ pull_request_template.md
├─ docs/                        # 本文档集
├─ backend/
│  ├─ pyproject.toml / uv.lock  # 含 ruff、pytest、import-linter 配置；console script aics-api、aics-cli
│  ├─ prompts.lock.json         # 提示词版本锁（python -m aics.core.prompts check|update）
│  ├─ alembic.ini
│  ├─ migrations/               # env.py（async）、versions/（0001 users、roles）
│  ├─ src/aics/
│  │  ├─ main.py                # create_app()、run()（aics-api）
│  │  ├─ health.py              # /healthz、/readyz（PG、Redis、RabbitMQ、Qdrant 并发检查，单项超时）
│  │  ├─ cli.py                 # aics-cli：bootstrap-admin、reindex、reconcile
│  │  ├─ core/                  # config.py logging.py errors.py security.py deps.py
│  │  │                         # tokens.py（唯一 token 计数）textsearch.py（按应用 jieba 分词器缓存 + build_tsquery）
│  │  │                         # models.py（AICS_MODELS 注册表）prompts.py（front-matter 提示词加载）
│  │  ├─ db/                    # engine.py base.py scoped.py（AppScopedRepository）models/*.py
│  │  ├─ modules/
│  │  │  ├─ auth/ apps/ apikeys/ knowledge/ chat/ feedback/ eval/ stats/ audit/
│  │  │  │  # 每个模块：router.py schemas.py service.py repository.py
│  │  │  │  # knowledge/chunk_search.py 实现 rag.ports.ChunkSearch；eval/prompts/eval_judge.md
│  │  ├─ rag/
│  │  │  ├─ graph.py state.py run.py（run_rag、RunMode、RagInput、RagResult）
│  │  │  ├─ config.py            # AppRagConfig / IntentConfig / HandoffConfig / ChunkConfig（唯一定义）
│  │  │  ├─ ports.py             # MemoryPort、ChunkSearch 接口
│  │  │  ├─ intent/              # normalize.py rules.py templates.py fallback.py schema.py（纯函数）
│  │  │  ├─ nodes/               # guard intent_match load_context condense_classify route retrieve fuse rerank judge generate postprocess replies
│  │  │  ├─ prompts/             # condense.md condense_classify.md generate.md judge.md chitchat.md（带 front-matter version）
│  │  │  └─ retrievers.py citations.py
│  │  ├─ memory/                # service.py context.py compactor.py facts.py recall.py store.py repository.py prompts/
│  │  ├─ ingest/                # service.py parsers/ chunker.py indexer.py injection.py
│  │  ├─ providers/             # base.py llm.py embedding.py rerank.py resilience.py
│  │  ├─ vectorstore/qdrant.py
│  │  ├─ storage/               # base.py local.py
│  │  └─ tasks/                 # celery_app.py（队列 ingest/context/eval/maintenance、beat 表）
│  │                            # ingest.py context.py eval.py maintenance.py —— 只调用 service
│  └─ tests/
│     ├─ unit/ integration/ e2e/
│     ├─ fixtures/docs/         # 测试用小文件（不含真实业务资料）
│     └─ conftest.py
├─ frontend/
│  ├─ package.json / package-lock.json / vite.config.ts / tsconfig*.json / eslint.config.js / .prettierrc.json
│  └─ src/ api/ views/ components/ stores/ router/ utils/   # main.ts、App.vue
├─ eval/
│  ├─ datasets/sample_ecommerce.csv   # 示例评测集（虚构数据）
│  └─ README.md
├─ deploy/
│  ├─ dev/docker-compose.yml          # 仅本机开发：Qdrant v1.18.2（服务器共用 KnowledgeFlow 的 Qdrant）
│  ├─ dev/.env.example
│  ├─ server/bootstrap/             # bootstrap.sh、postgres.sql、README.md：PG 库与用户、RabbitMQ vhost、Redis ACL（可选）
│  ├─ app/docker-compose.yml          # api / worker / beat / web（M6）
│  ├─ app/Dockerfile.backend / Dockerfile.web / nginx.conf
│  └─ scripts/ backup.sh restore.sh deploy.sh
├─ scripts/                     # 开发辅助：dev.ps1（一键启动 api+worker+web）
└─ storage/                     # 本地上传文件（gitignore）
```

import-linter 依赖规则在 L4 入口与 L3 之间多一层 `aics.health`（只依赖 core、db）。

模块职责与允许的依赖方向见[模块划分](../02-architecture/02-模块划分.md)；CI 用 import-linter 校验（配置在 `backend/pyproject.toml` 的 `[tool.importlinter]`）。
