# 项目目录结构（规划，代码阶段按此创建）

```
AIIntelligentCustomerService/
├─ README.md / .gitignore / .env.example / LICENSE / CHANGELOG.md
├─ .pre-commit-config.yaml
├─ .github/
│  ├─ workflows/ci.yml          # lint + test + gitleaks（push dev / PR）
│  ├─ workflows/release.yml     # 打 tag vX.Y.Z 时构建镜像、生成 Release
│  └─ pull_request_template.md
├─ docs/                        # 本文档集
├─ backend/
│  ├─ pyproject.toml / uv.lock
│  ├─ alembic.ini
│  ├─ migrations/
│  ├─ src/aics/
│  │  ├─ main.py                # create_app()
│  │  ├─ cli.py                 # aics-cli：bootstrap-admin、reindex、reconcile
│  │  ├─ core/                  # config.py logging.py errors.py security.py deps.py
│  │  ├─ db/                    # engine.py base.py models/*.py
│  │  ├─ modules/
│  │  │  ├─ auth/ apps/ apikeys/ knowledge/ chat/ feedback/ eval/ audit/ stats/
│  │  │  │  # 每个模块：router.py schemas.py service.py repository.py
│  │  ├─ rag/                   # graph.py state.py nodes/ prompts/ retrievers.py citations.py
│  │  ├─ ingest/                # parsers/ chunker.py tokenizer.py indexer.py
│  │  ├─ providers/             # base.py llm.py embedding.py rerank.py resilience.py
│  │  ├─ vectorstore/qdrant.py
│  │  ├─ storage/               # base.py local.py
│  │  └─ tasks/                 # celery_app.py ingest.py eval.py maintenance.py
│  └─ tests/
│     ├─ unit/ integration/ e2e/
│     ├─ fixtures/docs/         # 测试用小文件（不含真实业务资料）
│     └─ conftest.py
├─ frontend/
│  ├─ package.json / vite.config.ts / tsconfig.json
│  └─ src/ api/ views/ components/ stores/ router/ utils/
├─ eval/
│  ├─ datasets/sample_ecommerce.csv   # 示例评测集（虚构数据）
│  └─ README.md
├─ deploy/
│  ├─ server/docker-compose.yml       # Qdrant
│  ├─ server/.env.example
│  ├─ app/docker-compose.yml          # api / worker / beat / web（M6）
│  ├─ app/Dockerfile.backend / Dockerfile.web / nginx.conf
│  └─ scripts/ backup.sh restore.sh deploy.sh
├─ scripts/                     # 开发辅助：dev.ps1（一键启动 api+worker+web）
└─ storage/                     # 本地上传文件（gitignore）
```
