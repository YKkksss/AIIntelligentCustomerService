# 配置与环境变量

- 加载：`pydantic-settings`，前缀 `AICS_`，读取 `.env`；启动时校验，缺少必填项直接退出并提示。
- 优先级：环境变量 > `.env` > 默认值。
- 应用级的业务参数（检索阈值、会话空闲关闭、转人工模式、排队超时、服务时间、接入后无消息超时、Webhook 等）存数据库 `apps`，平台默认的会话参数存 `system_settings`（后台系统设置页修改），都不在环境变量里。
- 完整示例见根目录 `.env.example`（全部为占位符）。
