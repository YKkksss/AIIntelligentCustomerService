# 配置与环境变量

- 加载：`pydantic-settings`，前缀 `AICS_`，读取 `.env`（在 `backend/` 下运行时依次读仓库根目录 `../.env` 与 `backend/.env`，后者优先）；代码中通过 `aics.core.config.get_settings()` 获取；启动时校验，缺少必填项直接退出并提示。
- 优先级：环境变量 > `.env` > 默认值。
- 应用级的业务参数（检索阈值、会话空闲关闭、转人工模式、排队超时、服务时间、接入后无消息超时、Webhook 等）存数据库 `apps`，平台默认的会话参数存 `system_settings`（后台系统设置页修改），都不在环境变量里。
- 完整示例见根目录 `.env.example`（全部为占位符）。

**测试专用**（不进 `Settings`，只被测试读取）：`AICS_TEST_DB_URL`（集成测试库，未设置则跳过集成测试）、`AICS_TEST_QDRANT_URL`（`:memory:` = qdrant-client 内存模式）、`AICS_UPDATE_SNAPSHOTS=1`（更新解析快照）。单元测试的其余 `AICS_*` 由 `backend/tests/conftest.py` 的 `TEST_ENV` 提供。

**不是环境变量的约定**（写死在代码中，修改需改代码与文档）：Celery 队列 `ingest`、`context`、`eval`、`maintenance`（见 ADR-0003）；token 计数口径 `cl100k_base`（`aics.core.tokens`）。
